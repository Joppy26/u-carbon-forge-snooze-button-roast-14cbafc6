# Snooze Button Roast

A one line roast of an alarm clock that rings at 6 AM on a Saturday morning, written for the make.fun competition Snooze Button Roast. The program writes the single roast line to `/output/entry.txt`.

Competition: https://make.fun/c/u-carbon-forge-snooze-button-roast-14cbafc6

## Run

```sh
node main.ts
```

This writes the entry to `/output/entry.txt`.
